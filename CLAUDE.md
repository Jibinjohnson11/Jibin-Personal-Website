## Rules — always follow
- Premium, modern, minimal design; fully responsive (test at 360px, 768px, 1280px)
- Every page: one H1, logical H2/H3 order, unique title (<60 chars) and meta description (<160 chars), self-referencing canonical, Open Graph tags
- Semantic HTML, accessible (alt text, labels, visible focus states, colour contrast AA)
- All animations respect prefers-reduced-motion
- Images: WebP/AVIF via Astro's <Image>, explicit width/height, lazy-load below the fold
- Target Lighthouse 90+ on mobile for performance, accessibility, best practices, SEO
- Structured data only for content actually on the page; never invent reviews, ratings, or addresses
- Never invent client results, numbers, or testimonials; use [PLACEHOLDER] where content is missing
- Explain what you changed after each task

## Writing rules — all website copy
- All text must be 100% original. Never copy or closely paraphrase wording from other websites, templates, or competitor portfolios.
- Write like a real person talking to a client: clear, warm, confident, plain English.
- Use short sentences and varied sentence length. Use contractions (I'm, you'll, don't).
- Write in first person ("I build…"), never third person.
- Avoid AI-sounding phrases and filler, including: "In today's digital landscape", "elevate", "unlock", "seamless", "cutting-edge", "robust", "leverage", "delve", "game-changer", "take it to the next level", "passionate about", "dynamic", "results-driven".
- No superlatives I can't prove ("best", "No.1", "top", "leading").
- Avoid em dashes; use commas or full stops instead.
- Be specific: name the real project, tool, or task instead of vague claims.
- Use the copy I provide in content files as written; only edit it for fit, and tell me what you changed.
